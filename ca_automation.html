Overview

The Engineering Goal

Automating complex Indian tax compliance is historically rigid and prone to friction. The objective was to build an intelligent, language-agnostic FDE (Forward Deployed Engineering) platform capable of answering CA final syllabus queries accurately, mapping conversational intents, and autonomously executing multi-step tax filings on government portals while handling real-world roadblocks like CAPTCHAs.

The Approach

I developed a FastAPI backend orchestrating a LangGraph state-machine. Playwright handles secure portal navigation (downloading prefill.json, AIS/TIS) and structures data into Excel. I built a dynamic HTML/JS frontend featuring a Voice UI (STT/TTS) and a HITL (Human-in-the-Loop) chat interface for seamless CAPTCHA resolution. The entire system uses the OpenAI API for multilingual translation and is containerized via Docker.

Technical Deep Dive

Instead of building fragile bots that attempt to bypass CAPTCHAs, this platform implements production-grade HITL architecture. When the Playwright agent encounters a CAPTCHA while attempting to download AIS/TIS data, LangGraph pauses the state machine. The CAPTCHA image is instantly routed to the frontend chat UI, prompting the user. Once the user types the solution, the state resumes and Playwright injects the answer seamlessly.

# Conceptual LangGraph State Node for HITL Pause def handle_captcha_node(state: AgentState): if state["requires_captcha"]: # Pause execution, send CAPTCHA image via FastAPI to frontend return {"status": "WAITING_FOR_USER", "action": "SOLVE_CAPTCHA"} # Resume automation once user provides the solution return {"status": "CONTINUE_PORTAL_AUTOMATION"}

To maximize accessibility, the frontend features microphone integration for Speech-to-Text (STT) and Text-to-Speech (TTS). Users can request tax filings in regional languages (e.g., Hindi, Gujarati). The OpenAI API acts as an intelligent translation and routing layer, converting unstructured, multilingual voice requests into strict JSON variables required by the tax portal, effectively preventing data-entry hallucinations.

For CA-related queries, the platform uses a Vector Database to query the entire CA final syllabus. For tax filing, it orchestrates a complex data pipeline: downloading the `prefill.json` and AIS/TIS reports, parsing them into structured Excel tables, and cross-checking for missing data. If fields are missing, the agent triggers another HITL event, dynamically asking the user for the specific missing values before proceeding.
